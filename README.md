# Duck S3

A lightweight desktop app for managing S3 storage connections.

## Stack

- **Framework:** Tauri v2 + React + TypeScript
- **Build:** Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **State:** Zustand + React Query
- **Storage:** AWS SDK v3

## Getting Started

```bash
# Install dependencies
bun install

# Run dev server
bun run tauri dev

# Build desktop app
bun run tauri build
```
