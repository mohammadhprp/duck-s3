# Duck S3

A lightweight desktop app for managing S3 storage connections.

## Stack

- **Framework:** Tauri v2 + React + TypeScript
- **Build:** Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **State:** Zustand + React Query
- **Storage:** AWS SDK v3

## Getting Started

```bash
# Install dependencies
pnpm install

# Run dev server
pnpm tauri dev

# Build desktop app
pnpm tauri build
```
